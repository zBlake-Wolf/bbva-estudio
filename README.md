# Banca desde cero — guía de estudio

Sitio interactivo personal para estudiar conceptos bancarios y situaciones de atención telefónica.

- Basado principalmente en el manual de Banca Remota de diciembre de 2022 compartido para estudio.
- Complementa con explicaciones sencillas para entender los conceptos.
- **No es un sitio oficial de BBVA ni sustituye CUC, CCD, MAU o procedimientos vigentes.**
- Importes, horarios, límites, comisiones, autenticación y rutas operativas deben confirmarse en el CUC vigente.

Abre `index.html` para estudiar.
