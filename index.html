LO QUE MÁS SE CONFUNDE

Cliente ≠ contrato ≠ cuenta ≠ tarjeta ≠ CLABE

Regla: un código que identifica al banco puede mostrarse real; un dato que identifica a un cliente se muestra ficticio o enmascarado.

👤

CLABE BBVA

18 dígitos. El código bancario público real de BBVA México es 012.

Parte real + resto enmascarado:
012 XXX X XXXXXXXXXX X
012 = BBVA México.
💳

Número de tarjeta

Identifica una tarjeta concreta. No usamos tarjetas reales de clientes.

Ejemplo solo visual:
4000 1234 5678 9010
No se presenta como BIN real.

Datos públicos reales que sí conviene memorizar

BBVA México · código bancario012 · aparece como prefijo bancario de CLABE.
BBVA México · SWIFT/BICBCMRMXMMPYM · código publicado por BBVA para transferencias internacionales.
Banxico · clave SPEI/CEP40012 · Banxico lista a BBVA MEXICO con esta clave de institución.
CLABE18 dígitos · identifica la cuenta mexicana; la CLABE completa cambia por cliente.
IBANLas cuentas mexicanas no usan IBAN; para BBVA México se proporciona CLABE cuando corresponda.
ABABBVA México no usa código ABA propio; ABA es un identificador de bancos de EE. UU.
